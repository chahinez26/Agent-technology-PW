# USTHB — M1 SII — S2 | Agents Technology | 2025-2026

- **Lab 1:** Implementation of backward chaining for a rule‑based expert agent to prove a goal from a knowledge base.
- **Lab 2:** Introduction to JADE – creating agents, passing arguments, and launching them programmatically.
- **Lab 3:** Advanced JADE communication including point‑to‑point messaging, performative filtering, topic‑based broadcast, and object serialisation.
- **Lab 4:** JADE behaviours – agent migration, primitive behaviours (OneShot, Cyclic, Waker, Ticker), and composite parallel behaviours.
- **Lab 5:** Using the Directory Facilitator (DF) for service registration and discovery, with Buyer‑Seller communication exchanging serialised data.
